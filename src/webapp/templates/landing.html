How it works

  1. Drop in a file

    Pick a CSV or Excel file and the set of rules to check it against, or name your own required columns.

  2. Read the marked-up sheet

    Each problem gets a numbered mark on its cell and a matching note that says what is wrong and how to fix it.

  3. Take the cleaned copy

    Download the file with the safe fixes applied, plus a list of every change. Anything that needs a person is left for you.
